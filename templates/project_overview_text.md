# Project Overview: AI Job Search Agent

**What it is:** A prompt-driven workflow that turns any job description into a scored, application-ready package: fit score, apply recommendation, ATS keywords, tailored resume bullets, LinkedIn outreach, a cover letter opening, and interview prep.

**Problem:** Remote AI job searching is slow and inconsistent. Each posting needs the same analysis, and quality drops when it is done by hand under time pressure.

**Approach:** Seven prompts run in sequence, each with a defined input, output, and guardrails. A weighted 100-point rubric scores fit and penalizes roles centered on heavy coding, ML model building, or technical roadmap ownership. Results go into a CSV tracker so outcomes can be compared over time.

**Tools:** ChatGPT, Claude, or Gemini (tool-agnostic), plus a spreadsheet tracker.

**Project management angle:** Built as a repeatable process with clear stages, quality criteria, and success metrics, following Google Project Management practices.
